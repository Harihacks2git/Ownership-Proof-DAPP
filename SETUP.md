## 🔧 Prerequisites Installation

### Step 1: Install Node.js and npm

**Using Homebrew (macOS):**
```bash
brew install node
```

**Verify installation:**
```bash
node --version  # Should show v18+ or v20+
npm --version   # Should show 9+ or 10+
```

### Step 2: Install IPFS (Kubo)

**Using Homebrew (macOS):**
```bash
brew install ipfs
```

**Verify installation:**
```bash
ipfs --version  # Should show ipfs version 0.x.x
```

**Initialize IPFS:**
```bash
ipfs init
```

**Configure IPFS CORS (Required for browser access):**
```bash
ipfs config --json API.HTTPHeaders.Access-Control-Allow-Origin '["http://localhost:5173", "http://127.0.0.1:5173", "http://localhost:3000"]'
ipfs config --json API.HTTPHeaders.Access-Control-Allow-Methods '["PUT", "POST", "GET"]'
```

### Step 3: Install MetaMask Browser Extension

1. Visit [metamask.io](https://metamask.io/)
2. Install the browser extension for Chrome/Firefox/Brave
3. Create a new wallet or import existing one
4. **Save your seed phrase securely!**

## 🚀 Project Setup

### Step 1: Clone and Install Dependencies

```bash
# Navigate to project directory
cd Ownership-Proof-DAPP

# Install backend dependencies
cd backend
npm install
cd ..

# Install frontend dependencies
cd frontend
npm install
cd ..

# Install root dependencies (for authority server and indexer)
npm install express ethers dotenv
```

### Step 2: Configure Environment Variables

Create a `.env` file in the project root:

```bash
# Copy the example file
cp .env.example .env
```

Edit `.env` with your configuration:
```env
# Hardhat Local Network RPC
RPC_URL=http://127.0.0.1:8545

# Contract Address (will be filled after deployment)
CONTRACT_ADDR=

# Authority Private Key (will be generated by Hardhat)
AUTH_PRIVATE_KEY=

# IPFS Configuration
IPFS_API_URL=http://127.0.0.1:5001/api/v0
IPFS_GATEWAY_URL=http://127.0.0.1:8080/ipfs
```

### Step 3: Start Hardhat Local Blockchain

Open a **new terminal window** and run:

```bash
cd backend
npx hardhat node
```

**Keep this terminal running!** You should see:
- Started HTTP and WebSocket JSON-RPC server at http://127.0.0.1:8545/
- 20 test accounts with private keys and 10000 ETH each

**Copy Account #0 private key** - this will be your authority account.

### Step 4: Deploy Smart Contract

Open a **new terminal window** and run:

```bash
cd backend
npx hardhat run scripts/deploy.js --network localhost
```

You should see:
```
Deploying contracts with the account: 0x...
ContentRegistry deployed to: 0x...
```

**Copy the deployed contract address** (e.g., `0xe7f1725E7734CE288F8367e1Bb143E90bb3F0512`)

### Step 5: Update Configuration Files

**Update `.env` file:**
```env
CONTRACT_ADDR=0xe7f1725E7734CE288F8367e1Bb143E90bb3F0512  # Your deployed address
AUTH_PRIVATE_KEY=0xac0974bec39a17e36ba4a6b4d238ff944bacb478cbed5efcae784d7bf4f2ff80  # Account #0 private key
```

**Update `frontend/src/config.js`:**
```javascript
export const CONTRACT_CONFIG = {
  address: "0xe7f1725E7734CE288F8367e1Bb143E90bb3F0512",  // Your deployed address
  chainId: "31337" // Hardhat local network
};
```

### Step 6: Configure MetaMask for Local Network

1. Open MetaMask
2. Click network dropdown → "Add Network" → "Add a network manually"
3. Enter details:
   - **Network Name:** Hardhat Local
   - **RPC URL:** http://127.0.0.1:8545
   - **Chain ID:** 31337
   - **Currency Symbol:** ETH
4. Click "Save"

### Step 7: Import Test Account to MetaMask

1. In MetaMask, click account icon → "Import Account"
2. Paste **Account #1 private key** from Hardhat node output
   - Example: `0x59c6995e998f97a5a0044966f0945389dc9e86dae88c7a8412f4603b6b78690d`
3. This account has 10000 ETH for testing

## 🎮 Running the Application

You'll need **4 terminal windows** running simultaneously:

### Terminal 1: Hardhat Node (Blockchain)
```bash
cd backend
npx hardhat node
```
**Status:** Keep running - this is your local blockchain

### Terminal 2: IPFS Daemon
```bash
ipfs daemon
```
**Status:** Keep running - this handles file storage
**Check:** Visit http://127.0.0.1:5001/webui to see IPFS dashboard

### Terminal 3: Frontend (React App)
```bash
cd frontend
npm run dev
```
**Status:** Keep running - this is your web interface
**Access:** Open http://localhost:5173 in your browser

### Terminal 4: Authority Server (Optional)
```bash
node authority-server.js
```
**Status:** Keep running if you want to test authority CID updates
**Port:** Runs on http://localhost:3001

### Terminal 5: Event Indexer (Optional)
```bash
node indexer.js
```
**Status:** Keep running to log blockchain events to `event_db.json`

## 🎯 Using the Application

### First Time Setup

1. **Open browser** to http://localhost:5173
2. **Connect MetaMask:**
   - Click "Connect MetaMask"
   - Select "Hardhat Local" network
   - Choose the imported test account
   - Approve connection

3. **Verify connections:**
   - ✓ IPFS should show green (daemon running)
   - ✓ Smart Contract should show green (deployed)

### Register Your First Content

1. Click "Register Digital Content" section
2. Select a file (any document, image, video, or audio)
3. Enter a title and description
4. Click "Register Content"
5. Confirm transaction in MetaMask
6. Wait for confirmation (~2 seconds on local network)

### View Your Content

- Check "My Owned Contents" section
- Click "View Details & History" to see ownership timeline
- Click "View on IPFS" to see the actual file

### Transfer Ownership

1. Open content details
2. Scroll to "Transfer Ownership" section
3. Enter recipient's wallet address
4. Click "Transfer Ownership"
5. Confirm in MetaMask

## 🔍 Troubleshooting

### IPFS Connection Failed

**Problem:** Red "✗ IPFS" indicator

**Solutions:**
1. Check if IPFS daemon is running: `ipfs daemon`
2. Verify CORS configuration:
   ```bash
   ipfs config --json API.HTTPHeaders.Access-Control-Allow-Origin '["http://localhost:5173", "http://127.0.0.1:5173"]'
   ```
3. Restart IPFS daemon after config changes

### Smart Contract Not Connected

**Problem:** Red "✗ Smart Contract" indicator

**Solutions:**
1. Verify Hardhat node is running: `cd backend && npx hardhat node`
2. Check contract address in `frontend/src/config.js` matches deployed address
3. Redeploy contract: `cd backend && npx hardhat run scripts/deploy.js --network localhost`
4. Update contract address in config files

### MetaMask Transaction Errors

**Problem:** "Insufficient funds" or "Nonce too high"

**Solutions:**
1. **Insufficient funds:** Import a different test account from Hardhat
2. **Nonce too high:** 
   - MetaMask → Settings → Advanced → "Clear activity tab data"
   - Restart Hardhat node and redeploy contract

### File Already Registered Error

**Problem:** "This file has already been registered"

**Explanation:** The smart contract prevents duplicate CID registration

**Solutions:**
1. Use a different file
2. Modify the file slightly (add a space, change metadata)
3. This is expected behavior - it's a feature, not a bug!

### Port Already in Use

**Problem:** "Port 8545 already in use" or "Port 5173 already in use"

**Solutions:**
```bash
# Find and kill process on port 8545 (Hardhat)
lsof -ti:8545 | xargs kill -9

# Find and kill process on port 5173 (Vite)
lsof -ti:5173 | xargs kill -9

# Find and kill process on port 5001 (IPFS)
lsof -ti:5001 | xargs kill -9
```

### IPFS Upload Timeout

**Problem:** Upload hangs or times out

**Solutions:**
1. Check IPFS daemon is running
2. Try smaller files first (< 10MB)
3. Check IPFS logs: `ipfs log tail`

## 🔄 Restarting After Shutdown

When you restart your computer or close terminals:

1. **Start Hardhat node** (Terminal 1)
2. **Redeploy contract** (get new address)
3. **Update config files** with new contract address
4. **Start IPFS daemon** (Terminal 2)
5. **Start frontend** (Terminal 3)
6. **Reset MetaMask** (Settings → Advanced → Clear activity data)
